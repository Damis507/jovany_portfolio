Surl

Application mobile de suivi sportif personnel

Surl répond à un problème concret : maintenir une pratique sportive régulière sans accompagnement. L'app offre un suivi personnalisé pour tout type de sport — course, boxe, musculation, natation, tennis, etc.

Fonctionnalités : Authentification, saisie poids avec calcul IMC automatique, déclaration et historique des séances, objectifs hebdomadaires avec barre de progression (reset chaque lundi), graphiques d'évolution.

Architecture : Pattern MVC adapté Flutter. Collections Firestore : users, workouts, weightEntries, goals. State management via Riverpod, graphiques fl_chart.

Rôle : Conception complète — cahier des charges, maquettes Figma, développement Flutter, intégration Firebase.

Ubarda

Service de transport de biens sécurisé — "Voyager léger"

Ubarda est un service de livraison immédiate de biens personnels (bagages, colis), sécurisé par un cadenas NFC connecté. Le client déverrouille son colis via l'application — seul lui y a accès. En cas d'ouverture non autorisée, une notification est envoyée en temps réel.

App mobile : Vue.js + Supabase (OAuth), suivi GPS temps réel, réceptionneurs multiples, messagerie intégrée chauffeur/client. Maquette Figma complète.

Cadenas prototype : Arduino ESP32, module NFC PN532, GPS NEO-6M, batterie LiPo, actionneur serrure électronique.

Communication : site vitrine HTML/CSS/JS + chatbot, vidéo promo (After Effects + DaVinci Resolve), charte graphique complète.

Équipe : Maëlle Falch · Dalil Hammachi · Jovany Feltre

Inventor Race

Adaptation web d'un jeu de société — inventeurs & inventions

Adaptation numérique du jeu de plateau Hole Runner (EiSINe, Charleville-Mézières). Jeu 2–4 joueurs : chaque joueur doit atteindre le trou central en répondant à des questions sur les inventeurs. Deux modes de réponse — CASH (sans indice, +2 cases) et TRIO (avec 3 choix, +1 case ou barrière).

Défis techniques : Algorithme de pathfinding pour garantir qu'une barrière ne bloque jamais totalement un joueur. Gestion d'état partagé entre joueurs sans rechargement. Base de 60 questions structurées en JSON (2 niveaux, 2 modes).

Stack choisi : Web natif sans framework — contrôle total sur le rendu et la logique. Identité visuelle sombre/dorée, curseur engrenage animé en CSS.

Équipe : Jovany Feltre · Correntin Ribezzo
